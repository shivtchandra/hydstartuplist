## 🛠️ Tech Stack & Architecture

* **Framework:** Next.js 14 (App Router, Server Components & Static Site Generation)
* **Map Engine:** MapLibre GL / Vector Tiles
* **Database & Data Pipeline:** JSON datasets, Firebase Firestore, automated ATS scrapers (Greenhouse, Lever, Workday)
* **SEO & Structured Data:** Programmatic Dynamic Routes, OpenGraph cards, schema.org (`CollectionPage`, `ItemList`, `FAQPage`, `JobPosting`, `Place`)
